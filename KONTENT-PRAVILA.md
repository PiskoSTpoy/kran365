# Редполитика КРАН365

По шаблону скилла `seo-2026-playbook` (`references/paragraph-rules.md §5`). Обязательна к прочтению перед каждой новой статьёй/страницей.

## Кто говорит
- Персона: «диспетчерская служба, которая честно объясняет технику и цены» — не «братан», не «профессор», без наигранного маркетингового тона. Обращение — на «вы».
- Автор в подписи: **«Редакция КРАН365»** (реальных именованных авторов с фото нет — не выдумывать).

## Как пишем
- Первое предложение intro и каждой секции — тезис с фактом (цифра, срок, название техники/норматива). Стоп-фразы начала запрещены: «в этой статье», «сегодня разберём», «давайте», «многие задаются вопросом», «как известно», «стоит отметить», «важно понимать», «итак», «прежде всего», «ниже мы», «поговорим о», «рассмотрим».
- Средняя длина предложения 10-18 слов; абзац 2-5 предложений; секция 80-200 слов.
- Заголовки: H1 — вопрос как его ищут в поиске (≤90 знаков); H2 — одно свойство/подвопрос, с заглавной буквы, без точки, без кликбейта.
- Сущность (конкретная модель/класс техники, норматив, услуга) называется по имени в каждом абзаце. Абзац НЕ начинается с местоимения («он/она/это/этот/данный/такой»).
- Числа и нормативы (ФНП, ГОСТ, СНиП, грузоподъёмность, сроки) — только из реального источника, подтверждённого WebSearch, со ссылкой и датой проверки. Нет источника — пишем без цифры («точный норматив уточняйте в ФНП по подъёмным сооружениям»), не выдумываем номер.
- Таблица — при ≥3 сравниваемых параметров (тоннаж, вылет, цена и т.п.). Пример с реальными числами — при любом расчёте (смета, объём грунта, грузовая характеристика). FAQ — 4-6 вопросов в формулировках из реального спроса.

## Что запрещено
- Выдуманные факты, цифры, нормативы, отзывы, эксперты, счётчики просмотров/рейтингов без реальных данных.
- «Свой парк» / «собственные 120+ единиц техники» — КРАН365 диспетчер (см. бизнес-модель в памяти проекта), формулировка только «своя техника + проверенная партнёрская сеть».
- Прогнозы цен без источника; «гарантированно дешевле»; срочность ради срочности.

## Обязательные элементы страницы
- Обе даты (`опубликовано` / `обновлено`) через `<time datetime>`; если страницу не правили — только «опубликовано».
- «Факты проверены DD.MM.YYYY» в meta-row.
- TOC при ≥3 H2; каждый H2 с `id`.
- Блок «Источники · проверено DD.MM.YYYY» со ссылками на официальные документы/сайты производителей техники.
- JSON-LD: `BreadcrumbList` + `Article` (author = Organization «КРАН365») + `FAQPage` из видимых `<details>`.
- Связанные сущности («По теме») — реальные, привязанные к теме статьи, не рандомный список.

## Источники (белый список доменов)
- Нормативные: официальные тексты ФНП по подъёмным сооружениям, ГОСТ через нормативные базы (docs.cntd.ru, техэксперт), сайты Ростехнадзора.
- Технические: сайты производителей техники (Ивановец, Клинцы, Галичанин, Liebherr, XCMG, Zoomlion и т.п.) для грузовых характеристик.
- Рыночные данные — только если есть конкретный проверяемый источник; иначе — честная формулировка без цифры.
